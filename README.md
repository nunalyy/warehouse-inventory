   1.3 Тема проекта
   Проектирование и разработка информационной системы для управления складскими запасами на предприятии
   1.4 Цель проекта
   Разработать информационную систему для автоматизации учёта, контроля и управления складскими запасами, включая проектирование баз данных, пользовательских интерфейсов и бизнес-процессов.
   1.5 Задачи проекта
    1. Провести анализ предметной области «Складской учёт»
    2. Разработать модели бизнес-процессов в нотациях IDEF0, BPMN, DFD
    3. Спроектировать структуру базы данных и создать ER-диаграмму
    4. Разработать UML-диаграммы системы (диаграммы классов, прецедентов, последовательности)
    5. Создать ментальную карту системы
    6. Оформить полную документацию проекта в формате Markdown
   1.6 Аннотация
   Проект представляет собой комплексное проектирование информационной системы для управления складскими запасами. Система позволяет сотрудникам вести учёт товаров, отслеживать остатки, оформлять приход и расход, формировать отчёты и аналитику. В проекте реализованы все этапы проектирования: от анализа бизнес-процессов до проектирования базы данных и интерфейсов.
